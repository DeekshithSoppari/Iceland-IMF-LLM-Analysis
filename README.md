Iceland IMF Report Analysis
This project analyses Iceland’s 2023 IMF Article IV report using PDF extraction, section summaries, structured indicators and FAISS-based question answering. It includes a four-panel dashboard and a baseline versus multi-query retrieval comparison.
Run the notebook
1. Open 24174259_iceland_2022_2023_pdf.ipynb in Google Colab.
2. Upload 24174259 iceland 2022-2023.pdf.
3. Enter your Gemini API key when prompted.
4. Run the cells in order, including the correction cells.
Results are saved in /content/Iceland_IMF_Outputs. Disk caching reduces repeated API requests.

Automated scores do not replace source verification. Two banking indicators remain null because their evidence was not adequately recovered.
